# Task 2 – Deep Learning Image Classification

## Objective
To build a deep learning model that classifies images into different categories.

## Technologies Used
- Python
- Google Colab
- TensorFlow / Keras
- NumPy
- Pandas
- Matplotlib

## Project Description
This project uses deep learning techniques for image classification. The images are preprocessed and used to train a deep learning model. The model is evaluated using validation and test data.

## Key Steps
1. Load the image dataset.
2. Preprocess and resize the images.
3. Apply data augmentation where required.
4. Build the deep learning model.
5. Train the model.
6. Plot training and validation curves.
7. Evaluate the model.
8. Save the trained model.
9. Perform image prediction/inference.

## Environment Setup
The project can be run using Google Colab.

Required libraries:
- TensorFlow
- NumPy
- Pandas
- Matplotlib

## How to Run
1. Open the `.ipynb` notebook in Google Colab.
2. Upload or connect the required dataset.
3. Install/import the required libraries.
4. Run the notebook cells in order.
5. Check the training graphs and evaluation results.
6. Use the inference section to test predictions.

## Files
- `Task2.ipynb` – Main project notebook
- `Task2_Report.pdf` – Project report

## Result
The trained deep learning model classifies images into their respective categories and its performance is evaluated using appropriate metrics.

## Conclusion
The project demonstrates how deep learning can be used for image classification by preprocessing images, training a model, evaluating its performance, and making predictions.
